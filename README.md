# SakuraMedia 更多影片插件

定时抓取 JavDB 最新影片（有码 / 无码 / FC2），热度达标且主库没有的自动入库，
持续为主库补充最新影片。

## 工作方式

- 每天定时任务按发行日期从新到旧翻页抓取三个类型的最新列表（接口每个类型
  最多 99 页、4950 条），对每部影片先查主库，已有则跳过。
- 主库没有的抓取详情，按与宿主一致的热度公式过滤：低于 `min_heat`
  （默认 100）的影片不入库，等热度上涨后下一轮自然入库。
- 热度达标后交给宿主 `CatalogImportService` 入库，封面、剧照、演员、标签
  全部由宿主处理；已入库影片不会被重复导入或刷新。
- 图片下载失败的影片不入库，下一轮任务自然重试，避免无图影片永久残留。
- 单线程顺序执行，无本地数据落盘，无额外状态维护。

## 环境要求

宿主需支持 JavDB provider 与影片批量查询（Host API 10 及以上）。

## 安装

将插件根目录打包为 zip（根目录包含 `manifest.json`），从 SakuraMedia 的
「系统设置 → 插件」安装并启用，然后重启 API 和 APS 服务。

## 配置

在插件管理页配置，保存后重启服务生效。

```toml
[plugins.settings.sakuramedia_more_movies]
page_delay_ms = 350   # 列表翻页间隔（毫秒）
detail_delay_ms = 0   # 详情请求间隔（毫秒）
min_heat = 100        # 入库热度阈值，0 表示不过滤
```

任务 `sakuramedia_more_movies_sync` 默认每天 06:00 运行，可在任务中心手动
触发或调整 cron。
